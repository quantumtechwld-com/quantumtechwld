### S6 — Similar Projects Library ✅ NOVO

#### O que faz
Ao analisar um novo briefing, o sistema busca automaticamente projetos anteriores com escopo semelhante e injeta esse contexto no prompt do Gemini. A IA então referencia projetos reais como benchmarks de horas, budget e complexidade, tornando as estimativas progressivamente mais precisas.

#### Decisão de implementação — sem pgvector
A biblioteca pgvector não possui binários pré-compilados para Windows (PostgreSQL 15). Para não bloquear o desenvolvimento, os embeddings são armazenados como `TEXT` (JSON array de 768 floats) e a similaridade coseno é calculada em TypeScript. A migração para pgvector em produção (Linux) requer apenas alterar o tipo da coluna — o algoritmo permanece idêntico.

#### Schema (`prisma/schema.prisma`)
```prisma
model ReferenceProject {
  id              String    @id @default(cuid())
  title           String
  description     String    @db.Text
  projectType     String
  features        String[]
  techStack       String[]
  complexityScore Int
  hoursActual     Int
  budgetRange     String
  briefingId      String?   @unique
  briefing        Briefing? @relation(fields: [briefingId], references: [id])
  embedding       String    @db.Text  // JSON.stringify(float[768])
  createdAt       DateTime  @default(now())
}
```

#### Utilidades (`src/lib/embeddings.ts`)
- `generateEmbedding(text)` — chama `text-embedding-004` (Gemini) com `SEMANTIC_SIMILARITY`, retorna `number[]` de 768 dimensões.
- `buildEmbeddingText(data)` — serializa os campos relevantes do projeto em uma string normalizada para embedding.
- `cosineSimilarity(a, b)` — álgebra pura em TypeScript, sem dependências externas.

#### API endpoints
| Rota | Método | Auth | Descrição |
|------|--------|------|-----------|
| `/api/library/add` | POST | ✅ sessão | Recebe dados do projeto, gera embedding, persiste em `ReferenceProject` |
| `/api/library/similar` | POST | ❌ pública | Recebe texto, compara com todos os projetos, retorna top-N com score ≥ 0.7 |

#### Integração com S5 (`src/app/api/briefing/analyze/route.ts`)
1. Texto do briefing é convertido em embedding.
2. Todos os `ReferenceProject` são carregados e rankeados por cosine similarity.
3. Os 3 mais similares (threshold 0.7) são formatados e injetados no prompt do Gemini como bloco `PROJETOS SIMILARES JÁ ENTREGUES`.
4. Se a biblioteca estiver vazia ou o banco indisponível, o bloco é omitido silenciosamente — sem regressão no S5.

- Exibe projetos já cadastrados com badges de tech stack, score, horas e budget.

#### Ciclo de atualização
A biblioteca se torna mais precisa à medida que projetos são marcados como entregues no portal e cadastrados via `/portal/biblioteca`. Cada novo projeto melhora as estimativas dos briefings seguintes.
